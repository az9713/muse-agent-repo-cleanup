Act 1: The dead workflows

Two scheduled workflows — docs-drift.yml and weekly-digest.yml — had been failing every Monday for three weeks in both repos, because the CLAUDE_CODE_OAUTH_TOKEN secret was no longer maintained. GitHub eventually auto-disabled them. Here is every turn.

Two paths: re-issue the token (and repeat that chore every few weeks), or delete the dead workflows. The human chose deletion — and added a standing rule learned from it: prefer fixes that don’t need periodic refreshing.

Act 2: The lint failures

The human’s entire brief, verbatim: “Please look into why the CI fails. I do not want to receive any email regarding the CI failure.” That was it. No repo links, no logs, no guesses.

Chief — autonomous
Triage — both repos, both branches

Read the CI definition in .github/workflows/ci.yml for each repo: on Python 3.11 and 3.12, the pipeline installs dependencies, runs ruff check ., then pytest. The failure was the lint step — the tests had never even run in GitHub. Checked the latest main runs in both repos: red with the same lint failure. So the bypassed checks from Act 1 were pre-existing, and the merge was innocent.

Chief — autonomous
Reproduce locally — before touching GitHub

Cloned both repos and ran Ruff 0.16.7, the same linter CI uses: 12 violations in llm-ensemble-council, 13 in coilmem. The fixes were small and behavior-preserving: modernized type annotations (X | None), sorted imports, removed obsolete noqa directives, itertools.pairwise, parenthesized an implicitly-concatenated string, and reworked _extract_json’s try/except to avoid broad exception handling while keeping identical ValueError/TypeError behavior.

Chief — autonomous
Verification — two layers

Layer one: ruff check . — all checks passed in both repos. Layer two: the full test suites — 13 passed in llm-ensemble-council, 17 passed + 1 skipped in coilmem — plus standalone behavior checks on the reworked _extract_json (clean, embedded, malformed, empty, and None inputs). Nothing went to GitHub unproven.

The watch — proof without babysitting

Local proof isn’t CI proof, so a scheduled check was set to poll both PRs’ CI runs every 10 minutes and report back proactively — green or red — instead of making the human keep asking “how are the runs.” The human had asked for exactly that.

Status at publication: both PRs are open with CI running. The fixes passed everything verifiable locally; GitHub’s own runners deliver the final verdict. The two repos’ main branches still show the old red lint runs — expected, until the fix PRs are reviewed and merged.

Local-first, again

All 25 violations were fixed and proven on local clones — Ruff clean, 30 tests green — before GitHub was touched. Same discipline as yesterday’s CI repair.

Small, behavior-preserving diffs

Proof over assumption

The browser is an instrument
